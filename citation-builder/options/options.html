Formatting

APA uses sentence case for article and book titles. Words with inner capitals and acronyms (DNA, iPhone) are kept, and titles that already look sentence-cased are left alone. Turn off if proper nouns are being lowercased.

Online lookup Off by default

When on, Citation Builder may send the identifier (and nothing else) to api.crossref.org, openlibrary.org or export.arxiv.org to fetch the title, authors and publication details. These public services need no account. Turning this on asks for permission to contact those three sites only.

Keyboard shortcuts

Set shortcuts for “Cite the current page” and “Open the bibliography manager” at chrome://extensions/shortcuts.

  • Ctrl + Enter Save the citation (popup and editor)
  • / Search the bibliography
  • N Add a citation by hand
  • Ctrl + A Select all shown citations; Delete removes the selection (with undo)
