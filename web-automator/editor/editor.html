          Welcome to Web Automator

          1. Record: click the toolbar icon, press Record in this tab, then use the site as usual. Clicks, typing, selects, checkboxes, Enter, scrolling and page changes are captured.
          2. Edit: fine-tune steps here, add waits, assertions, extraction, if/else and loops.
          3. Play: run it on demand, once per CSV row, or on a schedule.

          To record and replay across page loads, Web Automator needs access to the sites you automate. Everything stays on this device.
