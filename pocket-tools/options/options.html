Pocket Tools

Passwords, QR codes, text stats and converters. Everything runs on this device.

Clipboard

Only applies to values copied from the password generator. The clipboard is overwritten with an empty value when the timer ends.

Conversion tooltip

This needs permission to run on the sites you visit. Without it you can still right-click a selection and choose Convert, which only touches the current page when you ask.

Keyboard shortcuts

    Pocket Tools does not claim any keys by default to avoid clashes. Assign them on the browser's shortcuts page.

    In the popup: Alt+1…4 switch tools, R regenerates and C copies on the password tab, arrow keys move between tabs.

    Reset

    Restore every setting (generator options, QR look, cities) to its default.
